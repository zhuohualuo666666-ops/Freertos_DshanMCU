堆是一块空闲的内存，，可以从中取出一部分，用完后释放。

1.案例：
char heap_buf[1024];//一块内存
int pos = 0;

void *my_malloc(int size)//在heap_buf分配size大小的空间，将原本pos存储的的位置信息给old_pos，新的pos值要加上size
{
	int old_pos = pos;
	pos += size;
	return &heap_buf[old_pos];
}

void my_free(void *buf)
{
	/* err */
}


int main(void)
{
	char ch = 65; // char ch = 'A';
	int i;
	char *buf = my_malloc(100);
	
	unsigned char uch = 200;
	
	for (i = 0; i < 26; i++)
		buf[i] = 'A' + i;
	
	return 0;
}

使用这种方式无法实现释放内存的功能，因为无法判断要释放的空间大小，需要一个“头部”
这个案例实现的功能是，将'A','B','C'···'Z'这26个字母存到heap_buf[0]开始的26个字节的空间里


2.堆的释放实现：
开辟一个100字节的内存空间，malloc函数里需要分配一个“头部”和100字节，
头部保存分配的空间大小，释放空间时，根据头部的信息进行判断大小进行释放

定义一个结构体功能struct head，包含元素由大小size和指针next_free：

struct head
{
    int size;
    struct head *next_free;
}

定义一个全局结构体变量g_heap：
struct head g_heap;

注：
全局变量g_heap中的size和头部中的size是两个概念，g_heap中的size没有意义，设为0；头部中的size记录当前这个块的大小。
全局变量g_heap中的next_free和头部中的next_free是两个概念，g_heap中的next_free指向第一个头部的位置，头部中的next_free指向下一个头部的位置


·一开始：
定义char heap_buf[1024]，相当于开辟了一块1024个字节的空间，这个空间目前还没有被分配，就是一个1024字节的空闲块。
全局结构体变量g_heap中的size无意义，next_free指针指向第一个可分配的块里，刚开辟完1024字节空间的时候也就是指向heap_buf[0]，假设为X。
在初始化堆的时候生成一个头部A，令这个头部的size等于1024(这块开辟的内存大小)，next_free指向NULL(还没有分配)。

·当分配100字节空间时，生成新的头部B：
B中size=1024-108(头部+100)，next_free指向NULL，
A中next_free指向B，
全局变量中的g_heap.size值为0，g_heap.next_free指向位置为X+108

·再分配50字节空间时，生成新的头部C：
C中size=1024-108-58，next_free指向NULL，
B中next_free指向C，
全局变量中的g_heap.size值为0，g_heap.next_free指向位置为X+108+58

·释放第一个分配的100字节空间时：
C中next_free指向A，
A中size=100，next_free指向NULL
全局变量中的g_heap.size值为0，g_heap.next_free指向位置为X，


这样的释放方式会造成内存碎片化
