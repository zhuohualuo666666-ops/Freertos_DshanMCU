设置事件组的函数：

EventBits_t xEventGroupSetBits( EventGroupHandle_t xEventGroup,
const EventBits_t uxBitsToSet )

等待事件组的函数：

EventBits_t xEventGroupWaitBits( EventGroupHandle_t xEventGroup,
const EventBits_t uxBitsToWaitFor,
const BaseType_t xClearOnExit,
const BaseType_t xWaitForAllBits,
TickType_t xTicksToWait );

事件组的唤醒跟uxBitsToSet，uxBitsToWaitFor，xWaitForAllBits三个参数强相关，uxBitsToSet设置唤醒位，uxBitsToWaitFor设置等待位，xWaitForAllBits设置逻辑关系；
当xWaitForAllBits这个参数设为pdTRUE，那么只有在uxBitsToSet值的为1的位数包含所有uxBitsToWaitFor值为1的位数时，任务才可以被事件组唤醒；
当xWaitForAllBits这个参数设为pdFALSE，那么uxBitsToSet值的为1的位数只需要包含一个和uxBitsToWaitFor值为1的位数就可以让任务被事件组唤醒
