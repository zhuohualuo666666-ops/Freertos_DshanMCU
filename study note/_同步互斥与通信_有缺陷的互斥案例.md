·全局变量方式
void LcdPrintTask(void *params)
{
	struct TaskPrintInfo *pInfo = params;
	uint32_t cnt = 0;
	int len;

	while (1)
	{
		/* 打印信息 */
		if (g_LCDCanUse)
		{
			g_LCDCanUse = 0;
			len = LCD_PrintString(pInfo->x, pInfo->y, pInfo->name);
			len += LCD_PrintString(len, pInfo->y, ":");
			LCD_PrintSignedVal(len, pInfo->y, cnt++);
			g_LCDCanUse = 1;
		
		}
			mdelay(500);		
	}
}

两个任务AB需要互斥使用该函数，如果A运行到if (g_LCDCanUse)和g_LCDCanUse = 0;中间时被切换，则B也可以运行，
因此使用全局变量来互斥有缺陷。



·全局变量加减方式
int LCD_PrintString(int x, int y,  char *str)
{
    static int bCanUse=1;
    bCanUse--;
    if(bCanUse==0)
    {
        bCanUse++;
        return 0;
    }
    else
    {
        bCanUse++;
        return -1;
    }
}

bCanUse--;这一句变为汇编指令分3步：1.从变量中读取值存入寄存器2.寄存器中执行减操作3.将修改后的值存回变量，
如果A执行到第1步时被切换，则B也可使用，B执行完第3步时切换，A继续运行，则A仍可使用


·关中断方式
int LCD_PrintString(int x, int y,  char *str)
{
    static int bCanUse=1;
    disable_irq();
    if(bCanUse)
    {
        bCanUse=0;
        enable_irq();
        bCanUse=1;
        return 0;
    }
        enable_irq();
        return -1;
}

修改全局变量过程中关闭中断，保护修改过程，可以解决互斥缺陷，
但由于A运行过程中B也会定期判断尝试获取使用权，导致CPU效率降低
